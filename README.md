# GREAT Greenland ROV (Aquarius Project)

A short blog from the GREAT Greenland ROV mission, part of the Aquarius Project.
Using the ROV Étaín, the team surveyed the seafloor off north-east Greenland:
an underwater volcano, an isolated seamount, two glacier-carved valleys, and a
fault line. Each site was mapped and photographed along the way.

The blog has an interactive survey map, a 3D model of the ROV, and a photo
gallery from the operations.
